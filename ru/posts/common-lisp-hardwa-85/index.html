Common Lisp & Hardware Security

Tagged as commonlisp, security

Written on 2026-10-04

Сегодня наткнулся на ещё одно интересное применение Common Lisp — SDK KeyNub для работы с аппаратным USB-ключом. Такой ключ хранит лицензию и нужен для использования коммерческого ПО. Получается, что можно на Common Lisp писать софт, для использования которого потребуется такой вот hardware-ключ.

Классно, что в SDK есть поддержка Common Lisp наряду с несколькими десятками других языков программирования. Причём для него есть отдельная страничка с документацией и примером — можно посмотреть, как прочитать лицензию из ключа.

Для меня это ещё один приятный признак того, что на Common Lisp пишут коммерческий софт.
