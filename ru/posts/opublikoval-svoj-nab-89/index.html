Опубликовал свой набор AI скиллов

Tagged as ai, commonlisp, opensource

Written on 2026-10-19

Вчера заметил, что репозиторий, в который я добавляю скиллы для разработки своих проектов, почему-то приватный. Не знаю, как так вышло, но пришло время исправить это недоразумение. Вот он: https://github.com/40ants/ai, пользуйтесь.

В основном там скиллы, помогающие программировать на Common Lisp, но есть кое-что и для веба.

Вот список скиллов на данный момент:

  • writing-common-lisp — соглашения по написанию Common Lisp кода в проектах с package-inferred ASDF-системами.
  • using-common-lisp-repl — безопасная работа с живым Lisp-образом через REPL: выполнение форм, перезагрузка файлов и поиск исходников зависимостей.
  • testing-with-rove — написание и запуск тестов с Rove, включая неочевидные особенности его API.
  • handling-json-in-common-lisp — работа с JSON через YASON, хеш-таблицами и serapeum:dict без путаницы между nil, false и null.
  • logging-with-log4cl — правильное логирование через log4cl, включая работу с форматными строками и package-inferred системами.
  • defining-clos-classes — паттерны определения CLOS-классов и конструкторов без дублирования значений по умолчанию.
  • writing-40ants-doc-documentation — создание и обновление документации с помощью 40ants-doc и docs-builder.
  • avoiding-common-lisp-pitfalls — набор неочевидных граблей Common Lisp и конкретных библиотек, на которые регулярно наступают AI-агенты.
  • clearing-asdf-fasl-cache — очистка протухшего кеша ASDF, когда изменения в исходниках никак не хотят подхватываться.
  • lint-common-lisp — проверка Common Lisp проектов с помощью Mallet и 40ants-linter. Первый ищет проблемы в исходниках, а второй загружает ASDF-систему через SBLint и находит пропущенные или лишние импорты.
  • nix-shell-playwright — воспроизводимое окружение Playwright через nix-shell для браузерных smoke-тестов и снятия скриншотов.

Скиллы упакованы как APM-плагины, поэтому их можно установить напрямую с GitHub, например так:


apm install 40ants/ai/plugins/common-lisp-skills --target codex

Репозиторий будет пополняться по мере того, как накопленные в разработке грабли превращаются в инструкции для AI-агентов. Подписывайтесь на репозиторий, ставьте звёздочки и предлагайте свои идеи скиллов!
