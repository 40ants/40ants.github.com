Последние три дня пытаюсь вытащить данные со своего Яндекс Диска

Tagged as yandex, живи

Written on 2026-10-13

Сначала пробовал использовать rclone, но в какой-то момент это API отключили. Пробовал вытаскивать данные через WebDAV - но он тоже уже не работает. При этом веб-интерфейс Яндекс Диска еще хоть как-то работает, хотя и не все файлы там можно скачать. Для некоторых файлов скачивание не работает, но доступны превью.

В итоге сегодня навайпкодил небольшое приложение, которое пытается вытащить хоть что-то, используя API веб-интерфейса Яндекс.Диска. Фишка этого приложения в том, что оно не просто пытается скачать файл рекурсивно из той папки, которую вы укажете, но и если файл недоступен, если оригинал недоступен, то эта утилита пытается скачать хотя бы какую-нибудь превью этого файла. Сейчас пытаюсь с этой штуки получится восстановить семейный архив, который у меня был на Яндекс Диске и который я почему-то по наивности своей не бэкапил.

Надеюсь и кому-то из вас эта утилитка тоже пригодится – не могу же я быть один такой, кто полагается на надежность облачных сервисов 🙂

Ссылка на репу: https://github.com/40ants/YDiskSaver
